TECHNICAL IMPLEMENTATION DETAILS:
---------------------------------
Transaction Business Rules:
- Only one currency field can be non-null per transaction
- Category must exist and be valid
- Period must be 6 digits in YYYYMM format
- Quincena must be Q1 or Q2
- Account_id is optional (nullable)
- Comments are optional
- is_recurring defaults to false
- debt_component is optional (principal/interest)

Currency Handling:
- Three separate decimal fields: amount_cad, amount_usd, amount_cop
- Exactly one must be non-null and non-zero
- Validation happens in service layer before database
- Currency auto-detected in entity getCurrency() method
- Amount extracted via getAmount() method based on currency

API Response Format (HATEOAS):
{
  "data": {...},
  "links": {"self": "...", "index": "..."},
  "message": "..."
