# Pockety — Session Progress (Initializer, Session 1)

## What this project is

Pockety is an existing Laravel + React (TypeScript, Inertia) personal finance app.
`app_spec.txt` is the **change specification** for the current work: eight change areas on
top of the already-built application. Behavior not specified there must stay as it is.

Authoritative inputs:
- `app_spec.txt` — the change spec (source of truth).
- `feature_list.json` — 87 end-to-end test cases covering every acceptance item, ordered by
  the spec's implementation order. **Only flip `passes` false → true. Never edit or remove.**
- `README.md` — project overview and setup.
- `init.sh` — environment bootstrap.
- `AGENTS.md` — environment/stack notes.

## Environment

- Local stack: pleets/devbox-station. Container: `web_app`, source mount `/var/www/vhosts`.
- App URL: http://dev.pockety.com:8080/ (host) / http://host.docker.internal:8080 (from container).
- **The repo's local `node_modules` are Linux binaries.** Running `npx vitest` / `tsc` on the
  macOS host fails with a rolldown native binding error. Run all JS tooling inside the container:

```bash
docker exec -u appuser -w /var/www/vhosts web_app bash -lc "npm run test:unit"
docker exec -u appuser -w /var/www/vhosts web_app bash -lc "npm run types:check"
docker exec -u appuser -w /var/www/vhosts web_app bash -lc "npm run build"
docker exec -u appuser -w /var/www/vhosts web_app bash -lc "php artisan test"
```

Browser tests (Playwright chromium is installed in the container):

```bash
docker exec -u appuser -w /var/www/vhosts web_app bash -lc \
  "PLAYWRIGHT_BASE_URL=http://host.docker.internal:8080 npx playwright test tests/browser/<spec>"
```

Note: browser helpers call `migrate:fresh --seed`, so running browser specs resets the dev
database to seeded state.
