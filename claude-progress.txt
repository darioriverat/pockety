## Technical Notes for Next Session

### Code Generation Pattern
The generateNextCode() method uses ORDERBY with CAST for numeric sorting:
```php
->orderByRaw('CAST(SUBSTRING(code, 2) AS UNSIGNED) DESC')
```
This ensures C9 comes before C10 (not C10, C9).

### Testing Pattern
Tests create models directly:
```php
Transaction::create([
    'date' => '2026-01-15',
    'period' => '202601',
    'category_id' => $category->id,
    'account_id' => $this->account->id,
    'amount_cad' => 100.00,
    'comments' => 'Test transaction',
]);
```

### Domain Entity Pattern
Services return domain entities, not Eloquent models:
- CategoryEntity from CategoryServiceInterface methods
- Controller converts entities to arrays for JSON response
- No Eloquent models leak to HTTP layer

### Validation
- Both is_debt_category and is_income_category true → 422 error
- Changing debt/income flags when transactions exist → 422 with specific message
- Delete blocked by transactions OR budgets → 422 with specific message
- Empty update request → 422 "At least one field must be provided"
