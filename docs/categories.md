# Categories

Categories classify your income, expenses, and debt-related activity so reports, budgets, and filters stay organized.

## What categories are for

Use categories to group transactions (for example groceries, rent, salary, or loan payments). Categories can be marked as expense, income, or debt-related so the right forms and reports treat them correctly. Inactive categories stay in history but drop out of pickers that only show active ones.

## Create a category

1. Open **Categories**.
2. Choose **Create category**.
3. Enter a name and choose the kind (expense, income, or debt).
4. Save.

The new category appears in the list and becomes available when you create or edit transactions.

## Edit a category

Each category has an edit action. You can change the name, kind (when allowed by the product rules for that category), and active status. Save to refresh the list.

Some flags may lock after certain history exists; the dialog explains when a field cannot change.

## Names are user data

Category names are values you enter. They are stored as typed and are not translated when you switch the application language. Only the surrounding UI chrome (labels, buttons, navigation) follows your language preference.
