# Pockety

Pockety is a personal finance manager for tracking accounts, categories, transactions, reconciliation, and period balances across CAD, USD, and COP.

Use these guides to learn how the shipped product works day to day. The documentation is written for end users and stays in English.

## Open these docs

From the project root, serve this folder with docsify:

```bash
npx --yes docsify-cli serve docs
```

Then open the URL printed in the terminal (usually `http://localhost:3000`). The sidebar lists every guide page.

## What you can do

- Create and edit bank, investment, liability, and receivable accounts
- Organize spending and income with categories you name yourself
- Record transactions in the currency you entered them in
- Check a month with reconciliation, then register month-end figures as period balances
- Prefer English or Spanish for the application UI (these guides remain English)

Your data stays private to your signed-in account. Names, notes, and other values you type are stored as you enter them.
